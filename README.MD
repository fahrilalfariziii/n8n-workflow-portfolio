# ⚡ n8n Workflow Portfolio

A collection of automated workflows built with **n8n** to streamline processes, integrate systems, and leverage AI/ML capabilities.

---

## 📌 About The Project

This repository serves as a portfolio of my automated workflows designed and implemented in **n8n**. It demonstrates various automation scenarios, third-party API integrations, data processing pipelines, and AI agent implementations (including RAG, Pinecone, Groq, LangChain agents, etc).

---


## 📥 How to Import Workflows into n8n
You can easily import any workflow JSON file from this repository into your n8n instance:

1. Clone or Download this repository:
```Bash
git clone https://github.com/fahrilalfariziii/n8n-workflow-portfolio.git
```
2. Open your n8n Editor UI.
3. Click on the ... (More options) menu in the top-right corner of the canvas.
4. Select Import from File (or Import from URL).
5. Choose the .json file of the desired workflow from your local cloned folder.
6. Configure any required Credentials (API Keys, Vector DB keys, Webhook tokens) inside the imported nodes.
7. Activate the workflow by toggling the Active switch at the top right.
